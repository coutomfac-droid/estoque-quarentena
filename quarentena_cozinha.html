🔧 Configurar Firebase
Configure uma vez só. Os dados ficarão salvos em nuvem para toda a equipe acessar em tempo real.
Passo 1
Acesse console.firebase.google.com → Criar projeto → nome "quarentena-bbq"
Passo 2
No projeto → Firestore Database → Criar banco (modo produção) → Regras: allow read, write: if true
Passo 3
Configurações do projeto ⚙️ → Seus apps → Web → Registrar app → copie os dados abaixo
💡 MODO DEMO (sem Firebase)
Se quiser testar agora sem configurar Firebase, use o modo local — dados ficam só neste dispositivo.
